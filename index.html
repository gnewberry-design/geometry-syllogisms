📖 Lesson Guide / Overview

Essential question: How can two conditional statements combine to support a valid conclusion?

Estimated time: 45–50 minutes. Prerequisites: Write conditional statements; write converse, biconditional, inverse, and contrapositive forms; identify hypotheses and conclusions.

🔑 Syllogism

A logical argument in which two statements lead to a conclusion.

🔑 Hypothesis

The “if” part of a conditional statement.

🔑 Conclusion

The “then” part of a conditional statement.

🔑 Law of Detachment

From “If p, then q” and “p is true,” conclude “q.”

🔑 Conditional statement

A statement of the form “If p, then q.”

💡 Key distinction: The Law of Syllogism chains two conditional statements. The Law of Detachment applies a conditional statement to a known true fact.

🔔 Warm-Up / Bell Ringer (5 minutes)

Statement: If a shape is a square, then it is a rectangle.

  1. What is the hypothesis?
  2. What is the conclusion?
  3. Write the converse.
  4. Is the converse always true? Explain.
👀 Reveal suggested answers

Hypothesis: the shape is a square. Conclusion: it is a rectangle. Converse: If a shape is a rectangle, then it is a square. The converse is false; a non-square rectangle is a counterexample.

👩‍🏫 I Do - Direct Instruction (Learn) (10 minutes)

🔗 Law of Syllogism

If p → q, and q → r, then p → r.

1️⃣ If a figure is a square, then it is a rectangle.
2️⃣ If a figure is a rectangle, then it has four sides.
✅ Therefore, if a figure is a square, then it has four sides.

📌 Law of Detachment

If p → q, and p is true, then q is true.

1️⃣ If an angle measures 90°, then it is a right angle.
2️⃣ Angle A measures 90°.
✅ Therefore, Angle A is a right angle.

⚠️ Watch for invalid chains

“If it rains, the ground gets wet” and “If the ground gets wet, the game is canceled” form a chain only if both conditional premises are accepted as true. Never assume a conclusion follows when the middle terms do not match.

Teacher think-aloud: “I find the conclusion of the first statement, look for that same idea as the hypothesis of the second statement, and then connect the first hypothesis to the second conclusion.”

🤝 We Do - Guided Practice (10 minutes)

Example A — Complete the chain

If a number is divisible by 8, then it is divisible by 4.
If a number is divisible by 4, then it is even.
What follows?

✅ Show conclusion

If a number is divisible by 8, then it is even. This is the Law of Syllogism.

Example B — Identify the law

If a triangle is equilateral, then all three sides are congruent.
Triangle ABC is equilateral.
Therefore, all three sides of triangle ABC are congruent.

✅ Show reasoning

Law of Detachment: the hypothesis is known to be true, so the conclusion follows.

Example C — Spot the problem

If a number is a multiple of 6, then it is even.
If a number is a multiple of 4, then it is even.
Can we conclude that every multiple of 6 is a multiple of 4?

🔍 Show explanation

No. The statements share a conclusion, not a matching middle link. For example, 6 is a multiple of 6 but not of 4.

✍️ You Do - Independent Practice (10–15 minutes)

  1. If a polygon is a square, then it has four right angles. If a polygon has four right angles, then it is a rectangle. Write a valid conclusion.
  2. If a number is divisible by 10, then it is divisible by 5. The number 70 is divisible by 10. What follows? Name the law.
  3. If a figure is a rhombus, then it is a parallelogram. If a figure is a parallelogram, then opposite sides are parallel. Write the syllogism conclusion.
  4. Write your own pair of conditional statements that forms a valid syllogism.
  5. Explain why these do not form a valid syllogism: “If a figure is a square, it has four sides” and “If a figure is a rectangle, it has four sides.”
🔐 Teacher answer key (expand after students finish)
  1. If a polygon is a square, then it is a rectangle.
  2. 70 is divisible by 5; Law of Detachment.
  3. If a figure is a rhombus, then opposite sides are parallel.
  4. Answers vary; check that the conclusion of the first conditional matches the hypothesis of the second.
  5. Both statements end with the same conclusion; neither links to the other's hypothesis.

🌈 Differentiation / Accommodations

🧩 Support (<60%)

Color-code p, q, and r; give sentence frames; model one chain at a time; provide read-aloud directions and frequent checks.

🌱 Develop (60–79%)

Use partially completed chains, partner discussion, and feedback on mismatched middle statements.

🚀 Extend (80–100%)

Create original geometry syllogisms, identify invalid reasoning, and explain the distinction between syllogism and detachment.

IEP/504: Apply each student's documented accommodations, including extended time, chunked tasks, alternative response methods, or small-group assistance as appropriate. Reteach and reassess students below 80%.
